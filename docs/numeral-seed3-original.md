# 数詞seed3の全入力比較

2026-10-13。seed1/seed2の既知入力に一致した後、同じ固定生成器でseed3・count=128・max_units=16を追加。葵・茜とも128入力を通常SDKで採取し、全256件の正常終了・入力hash・CP932整形読み・native report hash・保存原版WAVのサイズとSHA256を検証した。

clean 24afedf・Go1.26.8・CGO=0の比較バイナリを固定し、全入力をGoに渡した。両声とも3件の整形読み差を発見。入力や失敗例を削らず、全128件の結果を[変更前の全比較](evidence/numeral-seed3-reading-baseline.json)に保存した。`AOIKANE_NUMERAL_SEED3_READING_AUDIT=1` / `TestRandomNumeralSeed3ReadingOriginal` は全128文×両声を読み、現時点で計6読み差により失敗する。既知失敗を含むため通常回帰からは明示的な監査として分離している。

## 原版の処理観測

[全3入力の原版観測](evidence/numeral-seed3-residual-akane-original.json)は数詞enter/leaveの対応・全stage数・助数詞引数を検証し、独立SDK整形読みに一致した。フロントエンドのみの観測であり、Goの波形一致は証明しない。

- case11 `秒本０は9８二5．十8十八年。`：原版は後半を `十`、`８十`、`八` と読み、ジュー＋ハチジュー＋ハチを連結してアクセント表で再解釈する。Goは最後のジューハチを分け、年の前のグループが異なる。
- case72 `学校五A8学校の.1９・９万2。`：原版は `１９・９万２` をジュ―キューノ／キューマン／ニと読む。Goは中点をテンと読む。
- case124 `８億京5二秒9九5％読むは。`：原版は大単位から始まる数詞でも、秒の直前の二にビョーを結合し、ニビョーの1グループにする。Goはニとビョーを分けてしまう。末尾が単位か、途中に単位があるだけかの区別が次の調査点。

この3/128という比率は完成度を示さない。任意文章・全設定・全CPUでの一致は未達。seed2全128文×両声の波形比較は別プロセスで継続している。

後続の[途中の大単位と秒の修正](interior-unit-seconds-original.md)でcase124を解消し、seed3の差は両声ともcase11・72の2文になった。追加32読み・4WAV全体が原版と一致した。

[中点と単位列の修正](point-unit-tail-original.md)でcase72を解消し、両声とも残るcase11の1文になった。

[小数点後の単位と数字片の修正](decimal-unit-stream-original.md)でcase11も解消し、両声の全128入力の読みが一致した。全入力のゲートを環境変数なしの通常回帰へ昇格した。任意入力・全波形の一致は依然として未証明。
