# Pure Go版とDLL版の分離

2026-10-14。DLL版と原版の直接観測・認証・ランタイム梱包は非公開のaoikane-dllへ保持し、Pure Go版を別の公開aoikaneへ新しいGit履歴で取り込んだ。

公開版はビルドタグなしでPure Go経路を使う。元DLL・ライセンス入りランタイム・ONNX Runtimeの共有ライブラリ・そのアダプター・認証取得ツールを含めない。辞書、モデル、再構築したGoの各処理、採取済みの読み・波形参照と検証記録を保持する。

公開対象のファイル検査では、認証トークン・秘密鍵パターン、個人用ホームパス、元DLL、ライセンスファイルは見つからなかった。既存の非公開Git履歴を公開側へ移していない。

CGO=0・ビルドタグなしの全パッケージテストが通過。Windows amd64、Linux amd64/arm64のCLIをビルドし、WindowsのCLIで両声を取得できた。標準の依存一覧に元DLLローダー、ONNX Runtimeアダプター、puregoのFFI依存は含まれない。

公開版のHTTP APIへ接続する比較設定AOIKANE_PUREGO_URLをDLL側の通常原版WAVテストへ追加。[分離後の音声比較](evidence/repository-split-original.json)で一回転の葵・茜の2WAVを元SDKと比較し、独立原版採取とも再hash・全バイト一致を確認した。公開版比較バイナリは初回取り込み77358a2からビルドしたもので、CGO=0・タグ指定なし。有限入力の移行確認であり、任意入力・全設定・全CPUの完成を意味しない。
