# 単位列と「秒」の接続

2026-10-13。数詞の途中の `秒` は、通常の助数詞接続だけでは原版と一致しなかった。`0京秒1` は時間パターンより先に零省略を適用して `ケイビョー / イチ` を読む。一方、`1京秒1` や `0京秒万八京Ｃ` は、大単位を含む整数片と文字通りの `秒` を別の読み群として保持する。

時間パターンの成立時には、先頭零に単位が続く場合も零省略を適用する。小単位の通常処理と末尾の数字対の処理は保持する。`01京秒１`・`〇一京秒一二` では、零省略後の数字＋大単位と `秒` を分離し、末尾は時間パターンの数字対として読む。裸の単位語に付く `秒` は、その単位のアクセントを保持し、平板なら単位末に落ちを置く。`京秒万` や `0千秒万` がこの分岐を使う。`零ｂ京` のような数字対の区切りは、直後の単位と `秒` を独立した語にする。
