# 単位の後ろの零とペア読み

2026-10-14。数詞seed7 case62「、零億兆）（分零・零A億零〇兆零。」の最後の単位列をGoは読み切れず、辞書の単語ごとの読みへ戻っていた。葵では句の区切りにも差があった。

原版は億を10b010、零〇を1043f0、兆を10b010、最後の零を1043f0へ渡す。[3入力の原版内部観測](evidence/rei-zero-unit-tail-akane-original.json)で全stage・数詞LIFO・戻り値・最終整形と独立SDKの一致を検証した。親100a90は0を返すが、作られた読みは最終整形に使われるため、0をそのまま記録する。内部観測はフロントエンドのみで、波形証明ではない。

Goの連結数詞の音声表引きにliteral零のレーを追加した。単位の後ろが複数桁の零を含む1043f0のペア読みの場合は、単位部分とペア部分を分けて元のアクセント群を保持する。チョーレーゼロを再分割してレー／ゼロへ崩さない。

通常SDKから関連20文と境界8文を両声で採取し、全56件の正式終了、DLL/入力/native report SHA256、入力順、CP932読み、実WAVのサイズ/SHA256を検証した。[全読み比較](evidence/rei-zero-unit-tail-reading-comparison.json)に新28文×両声とseed7全128文×両声を保持する。新28文はすべて一致して通常回帰へ追加。seed7 case62は両声で一致し、残る読み差はcase103の1文ずつ。入力の除外・置換はしない。

任意入力・全設定・全CPUの完全一致は未達。

数詞・文章処理の回帰は通過（文章73.693秒）、全ReadingOriginal通常回帰は146.663秒で通過、vetも通過した。seed7の全件を読むゲート付きテストも実行し、残るcase103の1文×両声だけが失敗することを確認した。
