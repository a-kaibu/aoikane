# 中点・横棒が続く数詞

2026-10-13。原版の100a90は、単一のコネクタだけでなく `零三・２－５` のように異なるコネクタを含む数詞列も1回で読む。Goは最初の中点までしかまとめず、後続の横棒と数字を別の語にしていた。数詞scannerでコネクタ列を保持し、原版の小数範囲・電話・汎用列の分岐を選択する。既存の日付、電話の数字対、小数からの範囲を先頭ゼロ判定より優先する。

整数部やノの前の `兆０` をValueで整数に潰さず、数詞片として `チョー / ゼロノ` のように保持する。範囲のタイは最後の数詞キーを復元し、10対0のジュッタイなどの既存促音を保持する。

横棒範囲の `!０` / `!〇` を適用する。例外として年・日・秒・％など、ルール表の明示suffixなら先頭ゼロもカラ読みを許可する。このsuffix集合を原版のパターン定義から読む。汎用コネクタ列の最後の単純な数字は、通常の助数詞の音変化キーを使わない。`01-8本` はハチホンであり、ハッポン/ハチボンにしない。単位で終わる列はその単位キーを保持し、`0・千分` のセンプン・平板アクセントを再現する。

中点の後に裸の単位があるとき、通常の小数に変換しない。後続助数詞があれば `2・千円` のように強いポーズ、助数詞がなければ `一・万` のようにノで接続する。ラベルのn/Jパターン差と、電話の後ろの単位も再構築した。日本語の小数部＋小単位は元の促音・濁音を適用し、`〇・八百` はハッピャク、英数字の `0・8百` はハチ/ヒャクになる。
