# Pocket TTS inference

Adapted from [CWBudde/go-pocket-tts](https://github.com/CWBudde/go-pocket-tts/tree/4b72d3af8be4676168712fec6077db22d8909fd5) under the accompanying MIT license. The runtime includes the small-model changes validated in [the Pocket TTS benchmark](../../../benchmarks/pocket-tts/README.md). Aoikane uses its local assets and precomputed voice data in both native and browser builds.

The embedded [6.9M REFL model configuration](https://github.com/kyutai-labs/pocket-tts/blob/v4.0.1/pocket_tts/config/english_7m_refl_2026-10.yaml) comes from Kyutai's MIT-licensed Pocket TTS.
